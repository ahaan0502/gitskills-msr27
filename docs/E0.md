# E0 - Data preparation

Status: complete. E1-E6 are not started.

## Scope

E0 establishes the reproducible dataset snapshot, parser agreement, date-coverage audit, and derived skill table needed by later experiments. The work is double-anonymous and keeps source data and large generated artifacts outside Git.

  - Closing front-matter fences accept three or more dashes.
  - YAML failures recover line-level `name` and `description` values and set `fm_recovered=True` while retaining `frontmatter_valid=False`.
  - Body lengths preserve the dataset's CRLF counting convention.

Integrity checks confirmed row count, distinct hashes, `repo_rank`, and all three flag columns.

## Known caveat

Sample `body_chars` agreement is 99.062%, below the original 99.5% target. The 125 disagreements are retained for follow-up parser-parity analysis and are documented rather than hidden. Full E0 artifacts were built and integrity-checked; parser-parity refinement should be completed before relying on that field in later experiments.

## Reproducibility record

```text
python scripts/00b_sample_to_parquet.py data/sample/agent_skills_sample.db --out data/sample_parquet
python scripts/04_validate_parser.py --raw data/sample_parquet --out outputs/validation_sample
python scripts/01_date_audit.py --raw data/sample_parquet --out outputs/date_audit_sample
python scripts/00_download.py
python scripts/01_date_audit.py --raw data/raw --out outputs/date_audit_full
python scripts/02_build_skills.py --raw data/raw --out outputs/skills.parquet --workers 1 --batch-size 2000
python scripts/03_flags.py --raw data/raw --skills outputs/skills.parquet --out outputs/skills_flags.parquet --template-min-repos 5 --bulk-repo-min-skills 50
```

The full parser initially hit an out-of-memory error from an unnecessary global sort; removing that sort fixed the issue. A user-requested pause also produced an unfinished Parquet file, so the build was safely restarted with writer finalization and completed successfully. The managed environment required the one-worker fallback; the multiprocessing option remains available in less restricted environments.
